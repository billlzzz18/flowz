# Specification: Storage Formats

Source: Flowz Implementation Specification (Part C)

## C.1 Directory Layout (User Home)

```
~/.flowz/
├── profile.yaml                    # generated by discovery
├── state/
│   ├── cron.db                     # SQLite
│   ├── jobs.db                     # SQLite
│   └── events.db                   # SQLite (optional, for replay)
├── harness/
│   ├── versions/
│   │   ├── index.json
│   │   └── 1.0.0.md
│   │   └── 1.0.1.md
│   ├── bank/
│   │   ├── prompt/
│   │   │   ├── thinking-runaway.md
│   │   │   └── silent-failure.md
│   │   ├── knowledge/
│   │   ├── runtime/
│   │   └── config/
│   └── current -> versions/1.0.1.md (symlink)
├── trajectory/
│   ├── index.json
│   └── <session-id>/
│       └── <trajectory-id>.jsonl
├── skills/
│   └── <skill-name>/
│       └── SKILL.md
├── credentials/                    # encrypted
│   └── <provider>.enc
└── logs/
    └── <date>.log
```

## C.6 Cron State Database Schema (SQLite)

Path: `~/.flowz/state/cron.db`

```sql
CREATE TABLE cron_runs (
    cron_id      TEXT PRIMARY KEY,
    last_run_at  TIMESTAMP,
    last_status  TEXT,           -- success | failed | timeout
    next_run_at  TIMESTAMP,
    run_count    INTEGER DEFAULT 0,
    updated_at   TIMESTAMP NOT NULL
);

CREATE TABLE cron_history (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    cron_id      TEXT NOT NULL,
    run_id       TEXT NOT NULL,
    started_at   TIMESTAMP NOT NULL,
    ended_at     TIMESTAMP,
    status       TEXT NOT NULL,
    error        TEXT,
    FOREIGN KEY (cron_id) REFERENCES cron_runs(cron_id)
);

CREATE INDEX idx_cron_history_cron_id ON cron_history(cron_id, started_at DESC);
```

## C.7 Jobs Database Schema (SQLite)

Path: `~/.flowz/state/jobs.db`

```sql
CREATE TABLE jobs (
    id           TEXT PRIMARY KEY,
    request_id   TEXT NOT NULL,
    source       TEXT NOT NULL,       -- mcp | cli | cron | evolution
    status       TEXT NOT NULL,       -- pending | running | completed | failed | timed_out | cancelled
    items_count  INTEGER NOT NULL,
    started_at   TIMESTAMP NOT NULL,
    ended_at     TIMESTAMP,
    result_json  TEXT,
    error        TEXT
);

CREATE TABLE job_items (
    id           TEXT PRIMARY KEY,
    job_id       TEXT NOT NULL,
    item_id      TEXT NOT NULL,
    status       TEXT NOT NULL,
    started_at   TIMESTAMP,
    ended_at     TIMESTAMP,
    backend      TEXT,
    result_json  TEXT,
    error        TEXT,
    FOREIGN KEY (job_id) REFERENCES jobs(id)
);

CREATE INDEX idx_job_items_job_id ON job_items(job_id);
```
