Notes in Canvas

1) Yes/No Decision ใช้ตอนเช็ก preconditions, มี release ไหม, มี PR ไหม, มีปัญหาไหม
2) Score Decision ใช้ตอนประเมินขนาด PR แบบ XS/S/M/L/XL และประเมินความเสี่ยงจาก additions / files / conflict
3) Select Decision ใช้ตอนเลือกภาษา, จัดกลุ่ม PR, จัดกลุ่ม issue, และเลือก fallback path
ภาพรวมลำดับการกระทำ เริ่มจากภาษา → ตรวจเงื่อนไข → ดึงข้อมูล → แยกประเภท → วิเคราะห์ความเสี่ยง → สรุปผล → จัดรูปแบบ → คัดลอก
จุดที่โฟลว์นี้สำคัญ มันไม่ใช่แค่สรุปข้อมูล แต่เป็นการ “คัดกรอง + ตัดสินใจ + จัดลำดับ” ก่อนส่งรายงานสุดท้าย
  • Precondition = ต้องผ่านก่อนถึงจะทำต่อ
  • Classification = แยก PR / issue เป็นหมวด
  • Prioritization = ดูขนาดและความเสี่ยง
  • Fallback = ถ้าไม่มีข้อมูลหลักให้ใช้ข้อมูลสำรอง
